# Explainable Neural Computing Lab Homepage

Jekyll/GitHub Pages homepage for the Explainable Neural Computing Lab, Department of Statistics, Sookmyung Women's University.

## Main files
- `index.html`: homepage content and section order
- `_includes/sidebar.html`: lab identity and navigation
- `_data/students.yml`: student list
- `_data/news.yml`: news list
- `assets/css/main.css`: layout and styling
- `_config.yml`: site title and metadata

## Local preview
Run Jekyll from the project root using your existing Ruby/Jekyll environment, then open the local server URL printed in the terminal.
